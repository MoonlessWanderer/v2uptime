# Changelog

## 1.5.0 — 2026-11-16

Initial public release.

- V2Ray/Xray connectivity monitoring with a public status page and admin panel.
- English and Persian public pages, mobile layouts, and light and dark themes.
- Ping charts, uptime history, incident tracking, and Telegram notifications.
- Server import, JSON backup and restore, and database backups.
- Linux installer, management menu, and offline amd64 and arm64 archives.
