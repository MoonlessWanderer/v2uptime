Vazirmatn (SIL Open Font License) is served locally from this folder as
Vazirmatn-Variable.woff2 — no CDN is used by the pages.

install.sh downloads it automatically, and the offline release archives
already contain it. To add it manually, download
fonts/webfonts/Vazirmatn[wght].woff2 from https://github.com/rastikerdar/vazirmatn
and save it here as Vazirmatn-Variable.woff2.

Without the file the pages fall back to Tahoma / system fonts.
